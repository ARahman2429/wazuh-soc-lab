# Wazuh SOC Lab — SSH Attack Detection & Automated Response

## Project Overview

An independently built and documented cybersecurity SOC laboratory designed to demonstrate the detection, investigation, and automated containment of simulated SSH authentication attacks using Wazuh.

The project was conducted in an isolated VirtualBox host-only network and demonstrates a practical SOC workflow from attack generation through endpoint telemetry, SIEM detection, alert analysis, and automated response.

## Objectives

- Simulate controlled SSH authentication attacks from a Kali Linux system.
- Capture authentication activity at the Linux endpoint.
- Ingest endpoint telemetry into Wazuh.
- Detect repeated SSH authentication failures using Wazuh rules.
- Investigate alerts and correlate attack activity.
- Configure and validate Wazuh Active Response.
- Demonstrate automated firewall-based containment.
- Monitor Windows endpoint activity using Sysmon.
- Validate File Integrity Monitoring (FIM) through controlled file lifecycle events.
- Map relevant security activity to MITRE ATT&CK techniques.
- Produce a complete evidence-backed technical report.

## Lab Architecture

The laboratory was implemented using isolated VirtualBox virtual machines connected through a host-only network.

**Network:** `192.168.56.0/24`

| Component | Role |
|---|---|
| Kali Linux | Attack simulation / security testing workstation |
| Wazuh Manager | SIEM, detection, correlation and Active Response |
| Ubuntu Linux | SSH-monitored target endpoint |
| Windows Endpoint | Sysmon and File Integrity Monitoring telemetry |

## Attack Simulation

A controlled SSH authentication test was performed against the Linux endpoint using an intentionally invalid account.

The test generated authentication failures that were observed at the endpoint through SSH/PAM logging and subsequently ingested by Wazuh.

The activity was intentionally limited to the isolated laboratory environment and was performed for defensive detection and response validation.

## Detection

Wazuh successfully received and analyzed the authentication events generated by the controlled SSH activity.

Relevant SSH authentication failures included repeated invalid-user and authentication-failure events originating from the Kali test system.

The detection workflow demonstrated the relationship between:

**Attack Source → Endpoint Authentication Logs → Wazuh Agent → Wazuh Manager → Detection Rule → Alert → Active Response**

## Automated Active Response

Wazuh Active Response was configured to associate the SSH brute-force detection with a firewall-drop action.

The configuration initially required troubleshooting due to an XML/configuration error. After correcting the configuration, the Wazuh configuration was successfully validated and the service was restored.

The controlled attack was subsequently re-triggered to validate the response workflow.

The resulting activity demonstrated automated containment of the qualifying source connection.

## Windows Sysmon & File Integrity Monitoring

The Windows endpoint was monitored using Sysmon to provide additional endpoint telemetry.

Wazuh File Integrity Monitoring was also validated through a controlled file lifecycle test involving:

1. File creation
2. File modification
3. File deletion

Wazuh generated corresponding FIM events for the tested lifecycle, providing evidence of endpoint-level file monitoring.

## MITRE ATT&CK

The project includes mapping of relevant detection activity to applicable MITRE ATT&CK techniques, including authentication-related activity and file deletion behavior.

The mapping is used to provide security context to the observed events rather than treating individual alerts as isolated log entries.
